# Python Breakout
A basic and very rough breakout/Arkanoid style game demo created using python and pygame.
Just a single screen.

## Features
- Basic collision mechanics
- Some blocks take multiple hits to destroy
- Collectable tokens that fall from destoyed bricks
- Wide bat, super-ball, multi-ball, laser etc.

## Instructions
- Mouse to move
- Mouse button to fire (lasers!)
